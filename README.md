# LumaLab

A standalone virtual photography platform combining a realistic camera simulator, an immersive 3D studio, and an optical learning laboratory.

## Product direction

A hybrid of premium camera precision and futuristic creative technology. The platform serves beginners through professional photographers.

## Project status

- Phase 0: specification, brand system, architecture, scientific references, asset governance, QA and deployment plan.
- Phase 1: optical and exposure simulation foundation.
- No production application code is approved until the Phase 0 specification gate is complete.

## Repository boundaries

This repository is independent. Do not import code or deployment configuration from ChemLab or the personal portfolio.
